# Hub

The rangers' **spaceship** — their persistent home and the heart of the front-end
(like Helldivers' Super Destroyer). Reached from the Main Menu's Start.

Currently a placeholder screen with access points: **War Map** (opens the Star
Map / deploy select), **Loadout**, **Settings**. Will grow into a walkable 3D
ship and host party, matchmaking, store, and career surfaces.
